## 9. Inquiry List behaviour
Storage key/shape unchanged (`alnasr.inquiry.v1`). Active and unknown IDs behave as before (unknown kept, ignored). An **archived** line stays visible with its stored quantity and note, marked "Sample design — no longer available", is excluded from the RFQ payload with a visible notice, and can be removed with one button (the buyer can still submit valid active items). The API returns `422 archived_item` for archived IDs (distinct from `unknown_item`). Nothing is ever re-mapped to another design.
